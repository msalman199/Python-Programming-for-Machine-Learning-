## 🎯 Overview

In this lab, you built a **Linear Regression** model entirely from scratch using **NumPy**, without relying on high-level machine learning libraries. You trained the model on a simple dataset in which the target variable has a linear relationship with the feature, then measured how well it performed.

| 🧩 Stage | 📝 What You Did |
|----------|-----------------|
| **Implementation** | Built Linear Regression from scratch using NumPy and the Normal Equation |
| **Training** | Fit the model on a simple dataset with a linear feature–target relationship |
| **Evaluation** | Measured performance using the Mean Squared Error (MSE) metric |

## 🔑 Key Concepts

| 💡 Concept | 📖 Description |
|-----------|----------------|
| **Linear Regression** | One of the simplest and most fundamental machine learning algorithms; models a linear relationship between a feature and a target variable |
| **Normal Equation** | A closed-form mathematical solution used to compute the model parameters directly, without iterative optimization |
| **NumPy** | Python library used to implement the underlying matrix mathematics from scratch |
| **Training** | The process of fitting the model's parameters to the dataset |
| **Mean Squared Error (MSE)** | Evaluation metric that measures the model's performance |

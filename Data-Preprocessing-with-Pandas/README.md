## 📖 Overview

> 🧪 **Lab Environment:** Python with **Pandas** and **scikit-learn**.

This lab covers **data preprocessing**, a crucial step in the machine learning pipeline. You loaded a dataset using Pandas and displayed its first few rows, handled missing values by replacing them with column means, normalized numerical data using Min-Max scaling, and split the dataset into training and testing sets using `train_test_split` from scikit-learn.

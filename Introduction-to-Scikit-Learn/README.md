## 🎯 Overview

In this lab, you used **Scikit-Learn** to implement a linear regression model end to end: loading a built-in dataset, training the model, and evaluating how well it fits the data.

| 🧩 Stage | 📝 What You Did |
|----------|-----------------|
| **Data Loading** | Loaded a dataset using Scikit-Learn's built-in datasets |
| **Training** | Implemented linear regression using Scikit-Learn and trained the model on the dataset |
| **Evaluation** | Evaluated performance using Mean Squared Error (MSE) and R-squared score |

## 🔑 Key Concepts

| 💡 Concept | 📖 Description |
|-----------|----------------|
| **Scikit-Learn** | Python machine learning library used to load data, build the model, and evaluate it |
| **Built-in Datasets** | Ready-to-use datasets that ship with Scikit-Learn |
| **Linear Regression** | A regression model trained on the dataset to fit the data |
| **Mean Squared Error (MSE)** | Evaluation metric used to measure the model's performance |
| **R-squared Score** | Evaluation metric indicating how well the model fits your data |

## 🎯 Overview

This lab introduces the fundamentals of **neural network classification** using **TensorFlow** and **Keras**. You install the required libraries, build a simple neural network, train it on the classic **Iris dataset**, and evaluate how well it performs on unseen test data using **accuracy**.

| 🎓 Learning Objective | 🛠️ Tool / Dataset |
|---|---|
| Install the deep learning libraries | TensorFlow, Keras |
| Build and train a simple classification network | Keras, Iris dataset |
| Evaluate model performance on the test set | Accuracy metric |

## ✅ Key Accomplishments

In this lab, you have successfully:

- 📦 **Installed TensorFlow and Keras**
- 🏗️ **Built and trained a simple neural network** for classification using the Iris dataset
- 📊 **Evaluated the neural network's performance** on the test set using accuracy

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|---|---|
| **TensorFlow** | Open-source machine learning framework used as the backend for building and training neural networks |
| **Keras** | High-level neural network API used with TensorFlow to define and train models |
| **Neural Network** | A model made of connected layers that learns patterns from data |
| **Classification** | A machine learning task that assigns inputs to predefined categories |
| **Iris Dataset** | A classic benchmark dataset used for classification tasks |
| **Training / Test Set** | Data used to fit the model versus held-out data used to evaluate it |
| **Accuracy** | Metric measuring the proportion of correct predictions on the test set |
